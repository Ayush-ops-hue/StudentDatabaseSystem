# Student Database Management System

A simple student database management system developed using Java, JDBC, HTML, CSS, and MySQL.

## Features

- Add Student
- Update Student
- Delete Student
- Search Student
- View All Students

## Technologies Used

- Java
- JDBC
- MySQL
- HTML
- CSS

## Database

MySQL database stores:
- Student ID
- Name
- Email
- Course
- Marks

## Concepts Used

- CRUD Operations
- JDBC Connectivity
- SQL Queries
- Exception Handling

## How to Run

1. Install Java JDK
2. Install MySQL
3. Add MySQL Connector JAR
4. Create database tables
5. Compile Java files
6. Run application
